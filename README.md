# Virtual Hand Gesture Mouse 🖱️🖐️

A computer vision-based Python application that allows you to control your computer's mouse cursor entirely using hand gestures. By leveraging your webcam, this project tracks your hand landmarks in real-time to perform smooth mouse movements and clicks without needing any physical hardware.

### 🚀 Key Features
* **Touchless Mouse Control:** Move the cursor seamlessly across the screen by pointing and moving your index finger.
* **Gesture-Based Clicks:** Perform clicks effortlessly by bringing your thumb and index finger together (pinch gesture).
* **Smooth Tracking:** Utilizes advanced hand-landmark detection for low-latency and high-precision tracking.
* **Hardware-Free:** Works entirely through a standard built-in or external webcam.

### 🛠️ Tech Stack
* **Python** (Core programming language)
* **OpenCV** (For real-time video capture and frame processing)
* **MediaPipe** (Google's framework for robust hand and finger tracking)
* **PyAutoGUI** (For automating system-level mouse control)
